# M01 基础语法

> 本模块从第一个可运行程序出发，说明 C 源文件的基本组织方式、`main` 的入口约定、声明与语句的区别，以及最基础的标准输入输出。学完后应能编写、读懂并检查一个小型控制台程序，而不是只记住若干语法符号。

## E01.01 第一个 C 程序与基本结构

- **标签**：`程序结构` `编译` `链接` `stdio`
- **难度**：入门
- **前置**：无
- **关联**：E01.02、E01.03、E01.04、`<stdio.h>`

### 概念解释

一个最小的托管 C 程序通常由预处理指令、函数定义和注释组成；`main` 是程序启动后由运行环境调用的入口。源代码要先经预处理、编译和链接才成为可执行程序，`#include` 只取得库接口声明，链接器才负责把实现所需的标准库代码纳入最终程序。

### 语法要点

- `#include <stdio.h>` 指示预处理器引入标准输入输出接口声明，尖括号表示按实现规定的头文件搜索方式查找。
- 函数定义由返回类型、名称、参数列表和函数体组成；函数体用 `{}` 包围。
- `puts` 的原型为 `int puts(const char *s);`，它输出一个以 NUL 结尾的字符串并追加换行，失败时返回 `EOF`。
- 注释可写为 `/* ... */` 或 `// ...`；后者自 C99 起属于 ISO C。
- 编译器可发现语法和类型约束问题，但“成功编译”不证明所有运行路径都正确。

### 使用场景

适合第一次验证编译环境，以及搭建只有单一源文件的小工具。实际工程还会拆成多个翻译单元并使用构建系统，但入口和标准库声明的基本规则不变；不要把项目构建配置误认为 C 语言语法的一部分。

### 示例

```c
#include <stdio.h>

int main(void)
{
    if (puts("Hello, C!") == EOF)
    {
        return 1;
    }

    return 0;
}
```

### 注意事项

- 使用 `int main(void)`，不要写非标准的 `void main()`；后者不能表达标准规定的退出状态。
- 头文件提供声明而非 `puts` 的具体实现，遗漏 `#include <stdio.h>` 后碰巧链接成功也不是正确写法。
- 字符串中的 `\n` 表示换行；`puts` 已自动换行，再添加 `\n` 会产生额外空行。

### 常见问题

**问：`#include <stdio.h>` 是否会把整个标准库复制进程序？**

答：不会。该指令把声明等头文件内容纳入当前翻译单元，具体链接哪些实现由工具链和链接步骤决定；头文件文本包含与目标代码链接是两个不同阶段。

## E01.02 main 函数与程序入口

- **标签**：`程序结构` `返回值` `参数传递`
- **难度**：入门
- **前置**：E01.01
- **关联**：E01.05、E05.01、`<stdlib.h>`

### 概念解释

在托管实现中，`main` 是程序启动时由运行环境调用的特殊函数，不是操作系统直接跳到任意一条语句。它接收可选的命令行参数，并通过返回值或 `return` 语句向运行环境报告成功或失败状态。

### 语法要点

- 标准明确支持的两种形式是 `int main(void)` 和 `int main(int argc, char *argv[])`，也可使用等价的 `char **argv` 写法。
- `argc` 非负；`argv[argc]` 是空指针。当 `argc > 0` 时，`argv[0]` 表示程序名或空字符串，具体内容由运行环境提供。
- `return 0;` 表示成功；`<stdlib.h>` 的 `EXIT_SUCCESS`、`EXIT_FAILURE` 也可作为退出状态，其他值的可移植含义由实现规定。
- 到达 `main` 末尾等价于 `return 0;`，但显式返回通常更便于阅读。
- 独立式（freestanding）实现的入口名称和类型由实现定义，不能机械套用托管程序的 `main` 规则。

### 使用场景

无参数工具使用 `int main(void)`；需要读取文件名、模式或数值参数时使用带 `argc`、`argv` 的形式。库函数、回调函数以及嵌入式启动代码不应仅因“看起来相似”而自行命名为 `main`。

### 示例

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    if (argc > 1)
    {
        if (printf("first argument: %s\n", argv[1]) < 0)
        {
            return 1;
        }
    }
    else if (puts("no arguments") == EOF)
    {
        return 1;
    }

    return 0;
}
```

### 注意事项

- 访问 `argv[1]` 前必须确认 `argc > 1`，否则越过有效参数范围。
- 标准保证 `argv` 指向的参数字符串可由程序修改并保留最后写入的值，但修改时不得越过原字符串边界，也不能把指针数组当作可随意扩展的容器。
- 返回非零并不自动输出错误原因；面向用户的工具还应在标准错误流中给出可操作的诊断。

### 常见问题

**问：普通函数到达末尾也会自动返回 0 吗？**

答：不会。自动 `return 0` 是 `main` 的特例；其他非 `void` 函数若在有调用方使用其返回值的路径上未执行带值的 `return`，会产生未定义行为。

## E01.03 声明、定义、语句与代码块

- **标签**：`声明与定义` `作用域` `初始化` `未初始化`
- **难度**：入门
- **前置**：E01.01
- **关联**：E01.02、E02.04、E05.03

### 概念解释

声明把名称及其类型告诉编译器，定义还提供对象存储或函数体；语句描述执行动作，代码块则把声明和语句组织成一个作用域。区分这些概念，才能判断一个名称是否可见、对象是否已有值，以及某个定义是否会在链接时重复。

### 语法要点

- `int count = 0;` 是对象的声明兼定义；`extern int count;` 通常只声明别处定义的对象；`int add(int a, int b);` 是函数原型声明。
- 表达式语句以分号结束，如 `count = count + 1;`；控制语句包括 `if`、`for`、`while` 等。
- 复合语句 `{ ... }` 建立块作用域。自 C99 起，声明和语句可以在块内交替出现。
- 同名内层对象会隐藏外层对象，但外层对象并未被销毁；离开内层块后，外层名称重新可见。
- 自动存储期的局部对象若未初始化，其值是不确定的；读取这种不确定值可能产生未定义行为。

### 使用场景

代码块适合限制临时变量的可见范围，声明适合在接口头文件中共享类型和函数原型。不要为了“集中好看”而把所有变量放在函数顶部并长期复用；较短作用域通常能减少误用和隐藏错误。

### 示例

```c
#include <stdio.h>

int main(void)
{
    int total = 0;

    for (int i = 0; i < 3; ++i)
    {
        int square = i * i;
        total += square;
    }

    if (printf("total=%d\n", total) < 0)
    {
        return 1;
    }

    return 0;
}
```

### 注意事项

- `for` 初始子句中声明的 `i` 只在循环语句范围内可见，循环结束后不能继续使用。
- 初始化使用 `=`，相等比较使用 `==`；在条件中误写赋值会改变对象并可能导致逻辑错误。
- 一个对象可以有多个兼容声明，但具有外部链接的对象在整个程序中只能有一个定义；头文件里随意放置普通对象定义容易造成重复定义。

### 常见问题

**问：声明一个局部变量后，它的初值一定是 0 吗？**

答：不是。具有静态存储期的对象会零初始化，普通局部自动对象若未提供初始化器则没有可依赖的初值；应在读取前显式初始化或赋值。

## E01.04 使用 printf 进行格式化输出

- **标签**：`stdio` `表达式` `类型转换` `未定义行为`
- **难度**：入门
- **前置**：E01.01、E01.03
- **关联**：E01.05、E02.06、`<stdio.h>`

### 概念解释

`printf` 根据格式字符串把后续参数转换并写入标准输出。格式说明符既决定如何解释实参类型，也决定文本外观，因此实参与说明符的匹配是类型安全的一部分，而不只是排版细节。

### 语法要点

- 原型为 `int printf(const char *restrict format, ...);`，成功时返回写出的字符数，发生输出或编码错误时返回负值。
- 常用说明符包括 `%d`（`int`）、`%u`（`unsigned int`）、`%zu`（`size_t`）、`%c`（转换为 `int` 的字符）、`%s`（字符串）和 `%f`（`double`）；字面百分号写作 `%%`。
- 可变参数会经历默认实参提升，例如 `float` 转为 `double`，所以 `printf` 的 `%f` 同时用于这两种输入；`%lf` 在 `printf` 中与 `%f` 等价。
- 宽度、精度和标志可组合，如 `%.2f`、`%8d`、`%-8d`，但它们不修正类型不匹配。
- 格式说明符与对应实参不兼容，或要求的实参不存在，会产生未定义行为。

### 使用场景

适合诊断信息、表格化数值和命令行结果输出。不要把未经信任的文本直接当作格式字符串；要原样输出字符串时使用 `printf("%s", text)` 或 `puts`，其中 `text` 必须是有效的 NUL 终止字符串。

### 示例

```c
#include <stdio.h>

int main(void)
{
    unsigned int quantity = 3u;
    double unit_price = 12.5;
    size_t bytes = sizeof(unit_price);

    if (printf("quantity=%u, total=%.2f, bytes=%zu\n",
               quantity, quantity * unit_price, bytes) < 0)
    {
        return 1;
    }

    return 0;
}
```

### 注意事项

- `size_t` 应使用 `%zu`，不要凭平台猜测改用 `%d` 或 `%lu`。
- `printf` 返回负值表示输出失败；命令行工具若依赖输出完整性，应检查该结果而不是永远返回成功。
- 宽度不是内存缓冲区大小；需要构造有容量限制的字符串时应使用有边界意识的接口，而不是依赖显示宽度。

### 常见问题

**问：为什么 `float` 变量也能用 `%f`，不是说 `%f` 对应 `double` 吗？**

答：传递给可变参数函数的 `float` 会先被默认实参提升为 `double`，所以函数实际接收到的是 `double`；这不意味着可以把任意类型交给 `%f`。

## E01.05 使用 scanf 读取基本输入

- **标签**：`stdio` `输入验证` `类型转换` `未定义行为`
- **难度**：入门
- **前置**：E01.03、E01.04
- **关联**：E01.02、E02.06、E04.01、`<stdio.h>`

### 概念解释

`scanf` 按格式字符串解析标准输入，并通过调用方提供的地址保存结果。输入可能缺失、类型不符或中途失败，所以返回值是程序逻辑的一部分，不能假设用户一定按提示输入。

### 语法要点

- 原型为 `int scanf(const char *restrict format, ...);`，返回成功赋值的项目数；若首次转换前发生输入失败则返回 `EOF`，匹配失败可能返回 `0`。
- `%d` 需要 `int *`，`%lf` 需要 `double *`，因此普通对象前要使用取地址运算符 `&`；数组参数另有退变规则，见 E06.03。
- 数值转换会跳过前导空白；转换后未消费的字符仍留在输入流中，可能影响下一次读取。
- `%s` 会写入字符数组并追加 NUL，必须给出足以容纳输入的数组和最大字段宽度；单纯 `%s` 没有容量保护。
- 若转换结果不能由目标对象表示，ISO C 规定行为未定义；因此不可信数值输入更适合用 `fgets` 配合 `strtol` 等带范围检查的接口。

### 使用场景

`scanf` 适合格式固定、输入范围已由练习或协议限制的简单交互。面对任意用户输入、逐行配置或需要明确诊断的解析任务，不宜只依赖一次 `scanf`；先读完整行，再验证范围、尾随字符和转换错误通常更可靠。

### 示例

以下完整示例假定数值输入在目标类型可表示范围内：

```c
#include <stdio.h>

int main(void)
{
    int age;
    double height;

    if (puts("Enter age and height:") == EOF)
    {
        return 1;
    }

    if (scanf("%d%lf", &age, &height) != 2)
    {
        fputs("invalid input\n", stderr);
        return 1;
    }

    if (age < 0 || height <= 0.0)
    {
        fputs("invalid values\n", stderr);
        return 1;
    }

    if (printf("age=%d, height=%.2f\n", age, height) < 0)
    {
        return 1;
    }

    return 0;
}
```

### 注意事项

- 总是检查是否返回预期的赋值数量；失败时变量可能仍未写入，继续读取它们没有依据。
- 成功转换不代表业务值合理，年龄、尺寸等仍须检查允许范围。
- 数值输入后的换行通常仍留在流中；随后读取整行前要明确处理剩余字符，不要依赖“多试一次”碰巧恢复。

### 常见问题

**问：`scanf("%d", &value)` 返回 0 和返回 `EOF` 有何区别？**

答：返回 0 通常表示第一个待输入项与所需格式不匹配，尚未完成赋值；`EOF` 表示在首次转换成功前发生输入失败或到达文件末尾。两种情况都不能把 `value` 当作已读入的数据。
